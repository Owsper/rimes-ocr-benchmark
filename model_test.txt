# BEST MODEL RECOMMENDATION
========================================

Winner: PADDLEOCR (PP-OCRv4/v5)

- Best CER (15.43%) and best WER (47.50%) by a wide margin
- Best exact-match rate (5.00%)
- 2635 ms/img on CPU: fast enough for near-offline batch use

Reasons the others lose:
- tesseract : 55.76% CER. By far the fastest (159 ms) but too weak for
              messy handwriting; its single exact match (row 93,
              "Cordialement") is a short print-like token.
- trocr     : 21.38% CER is a solid second place, but the slowest
              (6843 ms/img) - ~2.6x paddleocr at worse quality.
- easyocr   : 60.49% CER, 0 exact matches. Not suitable for this task.

Practical guidance:
- Default engine for this dataset / French handwriting: paddleocr.
- If you need real-time (mobile/embedded) and can accept lower accuracy:
  tesseract (159 ms) is the only option under ~500 ms.
- trocr is worth keeping only if you have a GPU to cut its latency.
